# GROUND

Минимальный синтетический скелет PAF-волта (Product-as-a-Fractal vault) —
демонстрирует, куда контекст продукта ложится, если вы используете методологию
po-helper. Один пример нексуса лежит в `NEXUS/product/_index.md`.

Полное содержание методологии (онбординг, семейство `/paf-*` скиллов,
структура нексусов) — в скилле `paf-init`/`paf-install` репозитория
[poh-helper](https://github.com/po-helper-org/poh-helper), подключаемого как
submodule в `skills/poh-helper`.

Реальных данных, имён людей и ссылок на внутренние системы здесь нет —
это демо-воркспейс.
