# Нексус продукта (демо)

Пример узла-каталога PAF-волта. В реальном воркспейсе здесь накапливается
контекст о продукте: идея, видение, гэп между текущим состоянием и видением,
источники (интервью, документы, аналитика).

Это синтетический пример без реальных данных, поставляемый с
`po-helper-org/poh-harness`, чтобы структура каталога была видна сразу после
установки. Наполнение реальным контекстом — через методологию репозитория
[poh-helper](https://github.com/po-helper-org/poh-helper) (skills submodule).
