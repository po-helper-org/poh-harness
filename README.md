# poh-harness

Готовый к работе контур **DeepSeek Harness** с плагинами и настройками po-helper:
клонируете репозиторий, запускаете установщик, подключаете свою подписку — и
получаете рабочее место PO, а не голый харнесс, который ещё неделю настраивать.

## Что внутри

| Слой | Что даёт |
|---|---|
| **Раздел «Управление требованиями»** (`dsh-plugin-bft`) | Очередь БФТ из Backlog.md прямо в сайдбаре: поиск, превью требования, детальная страница с HTML-документом и мини-промтом, доска по стадиям проработки. Любое действие уводит в чат с готовым черновиком — отправляет всегда человек. |
| **Подписки как провайдеры** (`dsh-plugin-subscriptions`) | ChatGPT (Codex), Claude, Grok (X Premium), GitHub Copilot как LLM-провайдеры харнесса, вход по OAuth со страницы настроек. |
| **Backlog.md как нативные инструменты** | Задачи, доска и поиск по бэклогу доступны модели напрямую, без копипаста. |
| **Context7** | Актуальная документация библиотек в инструментах модели. |
| **Скиллы воркспейса** | `.claude/skills` вашего репозитория подключены как нативный skill-root — включая семейство `/bft-*`. |
| **Эксплуатация** | Скрипт запуска, автозапуск при логине (macOS), разбор известных грабель. |

Сам харнесс сюда не скопирован: установщик клонирует
[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)
на закреплённую проверенную версию. Так контур обновляется отдельно от апстрима,
а не расходится с ним форком.

## Как развернуть

Нужны **Node.js 22.19+ (или 24+)**, **pnpm 11.7** и **git**.
Полезно, но не обязательно: [Backlog.md](https://github.com/MrLesk/Backlog.md)
(`npm i -g backlog.md`) — без него раздел требований будет пустым.

```sh
git clone https://github.com/po-helper-org/poh-harness.git
cd poh-harness
./install.sh                    # спросит путь к вашему рабочему каталогу
./scripts/start-web.sh          # напечатает ссылку с токеном
```

Дальше — [docs/ONBOARDING.md](docs/ONBOARDING.md): подключение подписки и
настройка окружения под ваш воркспейс.

> **Рабочий каталог** — это репозиторий, требования которого вы ведёте (внутри
> `backlog/` и `bft/`), а не каталог харнесса. Установщик спросит путь и
> подставит его во все конфиги.

## HowToDemo

1. Открываете репозиторий.
2. `git clone` + `./install.sh`.
3. Получаете харнесс со всеми доработками и плагинами — раздел требований, доска,
   Backlog.md и скиллы уже подключены.
4. Подключаете свою подписку на странице настроек ([шаг 4](docs/ONBOARDING.md#шаг-4--подключить-подписку)).
5. Проходите онбординг окружения ([шаг 5](docs/ONBOARDING.md#шаг-5--настроить-окружение-под-свой-воркспейс)).
