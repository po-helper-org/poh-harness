# poh-mobile-skin

Мобильный скин poh-harness: DeepSeek Harness с телефона как PWA-приложение —
по образцу Claude Mobile.

| Где | Что |
|---|---|
| Главный экран | Приветствие по центру, поле ввода прижато к низу и стоит над клавиатурой, курсор сразу в поле |
| Меню (бургер) | Полный сайдбар dsh: сверху разделы плагинов («Требования», «Общение»), ниже чаты, внизу настройки; пустая на телефоне панель «Plugins» скрыта. Тап по пункту выполняет его и закрывает меню; раскрытие групп, поиск и выпадающие меню — нет |
| Настройки | Полный экран в стиле iOS: список разделов → раздел на весь экран с «‹ Назад» |
| Весь интерфейс | Документ неподвижен (нет сдвигов вбок, отскока, double-tap-зума), поля ввода 16px — iOS не зумит страницу при фокусе, учтены вырез и home indicator |
| PWA | meta для «На экран Домой» (standalone, status bar), `viewport-fit=cover`, `interactive-widget=resizes-content` |

Работает только на узком экране (`max-width: 768px`); десктоп не меняется.

## Как устроено

Только браузерная половина: `<style>` + свои узлы в `body` (бургер, плашка
«Назад»). **React-управляемые узлы dsh не переносятся и не удаляются** — это
роняло React (чёрный экран). Действия выполняются через родные контролы dsh:
бургер программно жмёт скрытый переключатель сайдбара, состояние читается с
атрибутов фрейма.

Ограничение iOS: Safari не поднимает клавиатуру программно без касания —
курсор стоит в поле, первый тап по экрану открывает клавиатуру.

## Привязка к версии dsh

Селекторы — хэш-классы CSS-модулей dsh (`pI_x6G_*`, `hHd-Xa_*`, `wSkVaW_*`,
`VOzbGW_*`, `bhn1Oq_*`) версии **0.1.7-rc.2**; они меняются с версией ядра.
После обновления харнесса прогоните стенд.

## Стенд

```sh
pnpm build
pnpm stand      # http://127.0.0.1:8765/fixture.html?autorun
```

Страница повторяет разметку dsh, подключает настоящий CSS dsh (извлекается из
`node_modules` запиненной версии) и собранный скин. Откройте её в мобильном
размере (DevTools → 393×852) — внизу отчёт: главный экран, меню и правила
его закрытия, каждый раздел настроек, отсутствие горизонтального
переполнения. `&remount` — режим, где модалка настроек пересоздаётся при
смене раздела.

Headless Chrome не сужает окно меньше 500px — ширину iPhone (393px) проверяйте
в обычном браузере с эмуляцией устройства.
