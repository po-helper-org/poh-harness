# HowToDemo

Пятиминутный сценарий приёмки: с нуля до рабочего раздела «Управление
требованиями» на синтетических данных, без своего рабочего каталога.

## 1. Клонировать и установить

```sh
git clone --recurse-submodules https://github.com/po-helper-org/poh-harness.git
cd poh-harness
./install.sh
```

На вопрос про рабочий каталог просто нажмите **Enter** — установщик поднимет
демо-воркспейс `workspace/` из этого репозитория: четыре задачи-примера БФТ
на разных стадиях проработки (`To Do`, `DEEP-WORK`, `DEEP-DONE`, `Cancelled`),
два HTML-документа требований, минимальный скелет PAF-волта.

## 2. Запустить

```sh
./scripts/start-web.sh
```

Откройте ссылку из вывода (`dsh web: http://127.0.0.1:3082/?token=…`).

## 3. Пройти раздел требований

1. Слева внизу — кнопка **«Управление требованиями»**. Открывает панель.
2. В очереди — четыре демо-задачи с заголовками `[БФТ] …`. Кликните по любой
   с иконкой документа (`DEMO-1` или `DEMO-2`) — откроется превью.
3. Из превью — «Открыть детальную страницу»: показывается HTML-документ
   требования (SMART-цель, как продемонстрировать) и мини-чат снизу.
4. Внизу панели — «Открыть доску требований»: те же четыре задачи разложены
   по стадиям проработки в виде канбан-доски.
5. Кнопка «Обновить» в панели открывает чат с подставленной командой синка —
   **не отправляйте её без реальных JIRA/Confluence** в демо-режиме, это
   просто демонстрация того, как кнопка уводит в чат, а не отправляет сама.

## 4. Проверить модельные инструменты

Откройте новый чат и спросите модель: «какие БФТ-задачи есть в бэклоге?» —
модель должна вызвать `mcp__backlog__task_list` и получить те же четыре
демо-задачи. Спросите «какие скиллы у тебя есть на bft» — должен найтись
`bft-writer` (из `skills/poh-bft-writer`, подключённого submodule'ом).

## 5. Подключить свою подписку

Без LLM-провайдера чат не работает. Если ещё не подключили — вернитесь к
[ONBOARDING.md, шаг 4](ONBOARDING.md#шаг-4--подключить-подписку).

## Что дальше

- Перейти на свой рабочий каталог: `./install.sh --workspace ~/projects/my-workspace`.
- Полная настройка окружения — [ONBOARDING.md, шаг 5](ONBOARDING.md#шаг-5--настроить-окружение-под-свой-воркспейс).
- Что-то не сошлось — [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
